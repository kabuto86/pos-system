KedaiPOS — Mockup UI

Rangka setiap bahagian sistem, dipecah ikut peranan. HTML statik dengan data palsu — tiada backend. Untuk dipersetujui sebelum kod API ditulis.

🧾 Juruwang

cashier/

Skrin POS kaunter — desktop/tablet landskap. Produk di kiri, troli di kanan, bayaran dalam modal. Satu-satunya peranan yang boleh terima bayaran.

Buka skrin POS

🍽️ Waiter

waiter/

Mobile-first untuk telefon. Paparan meja dan take-away, ambil pesanan. Tiada UI bayaran langsung. Buka dengan lebar telefon (390px) untuk rupa sebenar.

Buka paparan meja

📊 Admin kedai

admin/

Tauke / pengurus satu vendor. Sidebar navigasi, pemilih kedai di atas. Contoh: dashboard jualan hari ini.

Buka dashboard

🛡️ Superadmin

superadmin/

Panel platform — layout berasingan, warna gelap supaya tidak tertukar dengan admin kedai. Contoh: senarai vendor.

Buka senarai vendor

Peraturan reka bentuk yang dipakai

  • Bootstrap 5 sahaja — tiada inline CSS, tiada fail CSS tambahan
  • Setiap peranan ada layout sendiri: juruwang (skrin penuh), waiter (mudah alih), admin (sidebar terang), superadmin (sidebar gelap)
  • Nama kedai dan kaunter sentiasa kelihatan — vendor berbilang kedai tidak boleh tersilap kedai
  • Emoji dipapar pada skrin sahaja; resit bercetak tiada emoji
